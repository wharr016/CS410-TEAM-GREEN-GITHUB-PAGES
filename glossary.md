## Glossary

The following terms describe key concepts, features, and technologies associated with Team Green's VolunteerHub project.

### VolunteerHub
A proposed web-based platform designed to connect individual volunteers, volunteer teams, and organizations through a centralized system for discovering and managing volunteer opportunities.

### Individual Volunteer
A user who searches for volunteer opportunities based on location, distance, date, and other criteria and can contact organizations directly.

### Volunteer Team
A group of volunteers associated through a team account. Team members can discover opportunities and view events prioritized by their team.

### Volunteer Organization
An organization that creates and manages volunteer opportunity listings and communicates with interested volunteers.

### Volunteer Opportunity
An event or activity published by an organization seeking volunteer assistance.

### Location-Based Filtering
A feature that allows volunteers to find opportunities within a specified distance of their location.

### Event Expiration
A process that automatically excludes expired volunteer opportunities from search results.

### Team Priority Ranking
An algorithm that prioritizes volunteer opportunities selected by a user's team before displaying other matching events.

### Urgent Volunteer Notification
A feature designed to notify eligible volunteers when an organization identifies an urgent need for assistance.

### Contact Request
An initial message submitted by a volunteer to an organization expressing interest in an opportunity. The organization handles registration and follow-up outside VolunteerHub.

### Graphical User Interface (GUI)
The visual components of VolunteerHub that allow users to interact with the platform, including dashboards, forms, and event listings.

### Database
A structured collection of information used to store user accounts, organization details, team associations, volunteer opportunities, and contact requests.

### Frontend
The user-facing portion of VolunteerHub, developed using React, JavaScript, HTML, and CSS.

### Backend
The server-side portion of VolunteerHub, developed using Node.js and Express to process requests and communicate with the database.

### PostgreSQL
The relational database management system planned for storing VolunteerHub's application data.

### Application Programming Interface (API)
A software interface that allows VolunteerHub's frontend to communicate with its backend services.

### Prototype
An initial implementation of VolunteerHub used to demonstrate and evaluate the proposed system's functionality before developing the complete product.
